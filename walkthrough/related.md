# Free Zovo extensions for the files next to your structures

- FASTQ & FASTA Viewer opens sequence files, alignments and variant calls.
- NetCDF & HDF5 Viewer opens simulation output and other array data.
- 3D Model Viewer opens STL, OBJ, PLY and glTF meshes, for example printed models of a protein.

Each link opens the extension page. Nothing installs until you click Install there.
