# Changelog

## 0.1.0

- First release. Opens PDB, ENT, mmCIF, small-molecule CIF, PQR, SDF and MOL (V2000 and V3000), MOL2, XYZ and GRO files, and gzipped PDB and mmCIF files, as a 3D model drawn with 3Dmol.js.
- Cartoon, ball and stick, sticks, spheres and lines, an optional surface, and colors by chain, residue type, element, B-factor or secondary structure.
- Side tree of chains, residues and ligands with a filter and atom lists; atom details on a click; a sequence strip linked to the 3D view.
- Model and frame picker for NMR entries and multi-frame files.
- The file is read through VS Code, so it works the same in Remote SSH, WSL and container windows. No network calls.
- A .pdb file that holds Windows or .NET debug symbols gets a short note with buttons to open it elsewhere, never an error.
- Zovo Pro tools: Measure, Superpose and RMSD, Binding site report (1 free try each).
